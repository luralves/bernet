# BerNet

**BerNet** is a PyTorch extension for physics-informed neural networks (PINNs) that incorporates biases toward the correct solution of differential equations. Inspired by **Bernstein polynomials**, BerNet introduces a novel architectural design that blends approximation theory with physics constraints, enabling more stable training and improved accuracy on physics-governed problems.
